# 🍔 Online Food Delivery — Exploratory Data Analysis & Prediction (EDAP)

## 📌 Project Overview

This project focuses on analyzing an online food delivery dataset using **Exploratory Data Analysis (EDA)** and basic machine learning techniques. The main objective is to understand patterns in the data, identify useful insights through visualizations, and explore how machine learning can be used for prediction.

The project is implemented using Python and Jupyter Notebook, making it easy to understand and reproduce.

## 🎯 Objectives

- Understand the structure and characteristics of the dataset.
- Clean and preprocess the data for analysis.
- Identify patterns, trends, and relationships between variables.
- Create visualizations such as bar charts, histograms, and pie charts.
- Apply a Logistic Regression model for prediction.
- Understand the basic workflow of a data analysis and machine learning project.

## 🔍 Project Workflow

### 1. Data Loading
Load the online food delivery dataset into a Pandas DataFrame.

### 2. Data Understanding
Examine the dataset using methods such as `head()`, `info()`, `shape`, and `describe()` to understand its structure and contents.

### 3. Data Cleaning
Inspect the dataset for missing values, duplicate records, incorrect data types, and other data quality issues. Apply appropriate cleaning techniques where required.

### 4. Exploratory Data Analysis (EDA)
Analyze the dataset to understand the distribution of variables and discover patterns and relationships between different attributes.

### 5. Data Visualization
Create graphs and charts to present findings clearly, including bar charts, histograms, and pie charts where appropriate.

### 6. Machine Learning
Use Logistic Regression to explore prediction based on the selected target variable and relevant input features.

### 7. Model Evaluation
Evaluate the model using suitable classification metrics, such as accuracy, confusion matrix, precision, recall, and F1-score, where implemented in the notebook.

## 🚀 How to Run the Project

### Prerequisites

Install Python and Visual Studio Code, or use Jupyter Notebook.

### Step 1: Clone the Repository

```bash
git clone https://github.com/bhavya-kodidala/Online-Food-Delivery-Exploratory-Data-Analysis-Prediction-EDAP-.git
```

### Step 2: Open the Project Folder

```bash
cd Online-Food-Delivery-Exploratory-Data-Analysis-Prediction-EDAP-
```

### Step 3: Install the Required Libraries

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

### Step 4: Open Jupyter Notebook

```bash
jupyter notebook
```

Alternatively, open the project folder in VS Code and use the Jupyter extension to open the `.ipynb` files.

### Step 5: Run the Notebook

Open the required notebook, ensure the CSV dataset path is correct, and execute the cells from top to bottom.
